# CLAUDE.md

Standing rules for working on this project.

- **Ask for confirmation before making changes.** Show what will be created or changed and wait for approval.
- **Keep changes minimal and modular.** Do only what was asked. Prefer small, self-contained modules.
- **Update PROJECT.md after each significant change.** Keep its state, decisions, and to-do sections current.
- **Commit to git at each working milestone.**
- **Flag deviations.** When a suggestion differs from the current plan or requirements, say so and explain how it differs.

See [PROJECT.md](PROJECT.md) for decisions and [DATA.md](DATA.md) for data sources and terms.
